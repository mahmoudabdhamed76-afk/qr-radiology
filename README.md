# QR Radiology — إمداد QR للتوريدات الذكية للمراكز

نظام متكامل لإدارة طلبات التوريدات بين المراكز الطبية والمخزن الرئيسي عبر **أكواد QR** مع **موشن جرافيك احترافي (GSAP + SVG Motion Cinema)** ومزامنة لحظية فورية (SSE).

## المميزات
- **لوحة تحكم شاملة (`/`):** متابعة طلبات التوريد لحظياً، إدارة المخزون والأصناف، توليد وطباعة بوسترات QR لكل مركز، وإحصائيات مسح الأكواد والطلبات.
- **بوابة المراكز للموبايل (`/c/:code` و `/center`):** عرض الأصناف المتاحة والكميات المباشرة، طلب التوريدات بسهولة، ومتابعة مراحل تجهيز وشحن المهمة بالأنيمشن خطوة بخطوة.
- **Motion UI احترافي:** مبني بـ GSAP 3 + ScrollTrigger وحركات CSS مُسرّعة بالـ GPU مع دعم `prefers-reduced-motion` والوضع الليلي.

## التشغيل المحلي
```bash
npm install
npm start
```
